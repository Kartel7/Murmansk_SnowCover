# Murmansk_SnowCover
Code used to process and visualize AISORI climate data for the Murmansk region
Код, реализованный для обработки и визуализации климатических данных АИСОРИ [http://aisori-m.meteo.ru/]
<br>
# Данные включают:
- Snow_height_&_days_with_snow_processing_visualization: получение значений среднемесячной многолетней высоты снежного покрова (для графиков) и количества дней со снежным покровом (для карты) по станциям Мурманской области
- Solid_precipitation_receiving: получение среднегодовых многолетних значений твердых осадков (для карты) по станциям Мурманской области
- Station_points_receiving: получение пространственного слоя точек по координатам метеостанций Мурманской области согласно данным АИСОРИ
<br>
Полученные значения были соединены с точками метеостанций и интерполированы для визуализации
<br>
Эта работа выполнена в рамках курса «Тематическое картографирование», НИУ ВШЭ, 2024
